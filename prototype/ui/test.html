How to read this

Accuracy
Share of test cases the feature got exactly right (correct answers / all cases).
Precision
When the feature makes a positive call, how often it is right. Low precision = false positives (e.g. calling an address a "country").
Recall
Of the cases that should have been caught, how many were. Low recall = misses (e.g. a real country left unresolved).
False positive
Saying "yes/this type" when the truth is "no" - the costliest error, because it can change data silently.
n
Number of labelled cases behind the score. Small n means the number is indicative, not definitive.
Sentinel
A placeholder like -1, 999, or N/A that stands for "missing/refused", not a real value.
