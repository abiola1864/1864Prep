🔒 Your data never moves. The network carries a question and a verified answer; the record is read in place on this computer and only the answer is sent. Nothing is shared until you publish, and you can revoke any column at any time.

Settings

🔒 Your records never leave this computer. These settings only control optional features. Everything is off by default.

Region

Sets phone, date and place rules. The engine is generic; a region is just a pack of local conventions.

AI assistance optional · off by default

For the hard, meaning-based cases only (e.g. a place not in the list, or synonyms). AI only ever sees column headers and a small sample of values — never full records — and only suggests; its suggestions land in “Needs your attention”, never applied automatically.

Provider
Local server URL

A local model keeps everything on your machine. Cloud providers need your own API key and send the headers + sample to that provider.

Help improve the tool optional · off by default

If you switch this on, only your confirmed correction pairs (e.g. “Kastina → Katsina”) are shared to improve a common dictionary that ships in future updates. Your actual records are never shared. You can turn this off anytime.
