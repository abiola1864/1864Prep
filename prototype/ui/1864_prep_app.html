Where does it run?

Settings

🔒 Your records never leave this computer. These settings only control optional features. Everything is off by default.

Region

Sets phone, date and place rules. The engine is generic; a region is just a pack of local conventions.

AI assistance optional · off by default

AI is managed in one place now. It only ever helps where you allow it, sends masked samples (never full records), and suggests rather than changes.

Data types you work with

Tick the kinds of data you usually handle. It only helps the tool decide ambiguous columns; every column is still read from the data itself.

Help improve the tool optional · off by default

If you switch this on, only your confirmed correction pairs (e.g. “Kastina → Katsina”) are shared to improve a common dictionary that ships in future updates. Your actual records are never shared. You can turn this off anytime.

People & roles

The owner is an Administrator and can add members. Members can clean data; administrators can also manage people and settings. Stored on this device.

Security

For real protection, also enable full-disk encryption: FileVault (Mac) or BitLocker (Windows). A password here is a convenience lock, not encryption.

Version control steps you can reuse

Each saved version stores the exact steps taken for a cleaned file, the engine's decisions and your review. Apply one to a new file of the same type and skip the manual review; anything new or left over is still cleaned and shown. Good for speed, transparency and traceability.
